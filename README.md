# forgeProject

## Overview
This is my project developed for Clemson Forge's game design cohort.
The premise of the game is a timed puzzle game where you have to find your
car keys and leave for work after solving sets of intricate puzzles that
will unlock new rooms in your home.

## Core Gameplay Loop
You solve a puzzle in one room which will then open the next room,
containing a new puzzle as well as the one you just solved while a timer
shows you how long you have to get to work.
